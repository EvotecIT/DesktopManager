# Get-DesktopBackgroundColor
## SYNOPSIS
Gets the desktop background color.

## SYNTAX
### __AllParameterSets
```powershell
Get-DesktopBackgroundColor [<CommonParameters>]
```

## DESCRIPTION
Gets the desktop background color.

Returns the RGB color value currently used as the desktop background.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-DesktopBackgroundColor
```
