# Get-DesktopWindowKeepAlive
## SYNOPSIS
Lists windows currently kept alive.

## SYNTAX
### __AllParameterSets
```powershell
Get-DesktopWindowKeepAlive [<CommonParameters>]
```

## DESCRIPTION
Lists windows currently kept alive.

Returns information about windows that have active keep-alive timers.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-DesktopWindowKeepAlive
```
