# Stop-DesktopSlideshow
## SYNOPSIS
Stops the desktop wallpaper slideshow.

## SYNTAX
### __AllParameterSets
```powershell
Stop-DesktopSlideshow [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Stops the desktop wallpaper slideshow.

Ends any running wallpaper slideshow on all monitors.

## EXAMPLES

### EXAMPLE 1
```powershell
Stop-DesktopSlideshow
```
