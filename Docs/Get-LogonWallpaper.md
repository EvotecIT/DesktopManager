# Get-LogonWallpaper
## SYNOPSIS
Gets the current logon (lock screen) wallpaper.

## SYNTAX
### __AllParameterSets
```powershell
Get-LogonWallpaper [<CommonParameters>]
```

## DESCRIPTION
Retrieves the logon wallpaper path using native API when possible and falls back to registry.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-LogonWallpaper
```
